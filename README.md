# Desafio de Projeto: GitHub e Markdown da DIO
Este é um Projeto da **Formação GitHub Certification da DIO**, focado em praticar os conceitos de **Git**, **GitHub** e **Markdown**.

## 🚀 Objetivos
* Praticar a criação de repositórios.
* Entender o fluxo de colaboração (Issues, PRs).
* Formatar um bom `README.md` com Markdown.

## 🛠️ Ferramentas Utilizadas
- Git;
- GitHub;
- Markdown;
- VS Code (ou GitHub.dev).
